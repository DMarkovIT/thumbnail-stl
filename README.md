# Thumbnail STL

Эскизы и область предпросмотра для STL-файлов в проводнике Windows 10/11.
Модель рисуется на Direct3D 11 внутри проводника.

## Возможности

- Эскиз файла в папке вместо стандартной иконки.
- 3D-вид в области предпросмотра (`Alt+P`).
- Автоматическое вращение, вращение мышью, масштаб колесом, сброс двойным щелчком.
- Установка в профиль пользователя, без прав администратора.
- Бинарный и ASCII STL.

## Сборка

Нужны Visual Studio 2022/2026 с рабочей нагрузкой «Разработка классических
приложений на C++» и CMake 3.20 или новее.

```
cmake -S . -B build -G "Visual Studio 18 2026" -A x64
cmake --build build --config Release
```

Результат в `build/bin/Release`:

| Файл | Назначение |
|---|---|
| `STLPreview.dll` | Обработчик: `IThumbnailProvider` и `IPreviewHandler` |
| `STLPreviewHost.exe` | Процесс-хост предпросмотра |
| `stlprev-setup.exe` | Регистрация в реестре из командной строки |
| `stlprev-test.exe` | Тестовая утилита |

Установщик собирается отдельно и требует NSIS 3 (`scoop install nsis`):

```
make-installer.cmd
```

или

```
cmake --build build --config Release --target installer
```

Готовый файл — `dist/STLPreview-Setup-<версия>.exe`.

## Установка

Запустить `STLPreview-Setup-1.0.0.exe`. Установщик кладёт файлы в
`%LOCALAPPDATA%\Programs\STLPreview\1.0.0`, регистрирует обработчики в
`HKEY_CURRENT_USER\Software\Classes` и добавляет запись в «Программы и
компоненты». Тихая установка — ключ `/S`.

Удаление — из «Программ и компонентов» или:

```
"%LOCALAPPDATA%\Programs\STLPreview\1.0.0\Uninstall.exe" /S
```

Для работы с отладочной сборкой есть регистрация прямо из каталога сборки:

```
install.cmd
uninstall.cmd
build\bin\Release\stlprev-setup.exe status
```

## Управление в области предпросмотра

| Действие | Результат |
|---|---|
| Перетаскивание левой кнопкой | Вращение модели |
| Колесо мыши | Приближение и отдаление |
| Двойной щелчок | Исходный ракурс |
| Без действий | Автоматическое вращение |

## Устройство

`STLPreview.dll` содержит два COM-объекта:

- провайдер эскизов — загружается в процесс проводника;
- обработчик предпросмотра — запускается в отдельном процессе
  `STLPreviewHost.exe` через регистрацию `LocalServer32`.

Отдельный процесс нужен, чтобы падение рендера не роняло проводник.
Штатный суррогат `prevhost.exe` через `DllSurrogate` для установки в профиль
пользователя не подходит: суррогат запускает системный SCM, который читает
реестр от имени SYSTEM и не видит регистрацию в HKCU.

Геометрия загружается один раз в вершинный буфер: три вершины на треугольник,
у каждой нормаль грани. Камера ортографическая, кадр вписывается по фактической
проекции вершин. Сглаживание — MSAA 4x, эскизы дополнительно рисуются вдвое
крупнее и уменьшаются с усреднением. Фон берётся из темы Windows.

Крупные модели прореживаются: до 1,5 млн треугольников для эскиза и до 4 млн
для предпросмотра.

## Ограничения

- Проводник кэширует эскизы: у изменённого файла прежняя картинка может
  оставаться, пока кэш не обновится.
- Поддерживается только STL; 3MF, OBJ и STEP не открываются.
- Файлы больше 512 МБ не читаются.
- Пока область предпросмотра открыта, расширение рисует около 30 кадров в
  секунду.

## Отладка

Ошибки и ключевые события пишутся в
`%LOCALAPPDATA%\STLPreview\stlpreview.log`.

Тестовые модели создаёт `python tools\make_test_models.py testdata`, кадры
можно проверить утилитой `stlprev-test.exe` и измерить через
`python tools\analyze_bmp.py`.
